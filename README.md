# ML Assignment 3: Active Learning in Neural Netoworks

This assignment is an investigative study, conducted by a single student (Aphelele Zenzile) from the university 
of stellenbosch. The aim of this assignment is to compare and contrust three training approaches to neural networks, 
mainly two active learning approaches and passive learning approach functioning as a baseline for the study to 
evaluate the impact of active learning in neural netoworks.
